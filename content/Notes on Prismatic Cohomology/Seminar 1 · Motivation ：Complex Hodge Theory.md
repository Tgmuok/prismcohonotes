Cohomology：measuring how many 'loops' a space has.

Consider the spaces  $\mathbb{C}^{\times}=\mathbb{C} \setminus  \left\{ 0 \right\}$.

>[!notes]+ Def 1.1:
>
>>1-cohain on $\mathbb{C}^{\times}$ is a function on paths in $\mathbb{C}^{\times}$.
>>1-cochain $\varphi$ is called closed if for any continuous may  from a triangle ABC to  $\mathbb{C}^{\times}$, $\phi(f(AC))=$ $\phi(f(AB))+\phi(f(BC))$. It is called exact if it is of the form $\psi(ending \ point )-$ $\psi(starting \ point)$ for some function $\psi$ on $\mathbb{C}^{\times}$.
>
>>Define   
>>$$
>>\displaystyle{H^{1}_{{sing}}(\mathbb{C}^{\times},\mathbb{Z}):=\frac{\left \{ \mathbb{Z}-valued \ \ closed \ \ 1-cochains \right \} }{\left \{\mathbb{Z}-valued\ \ exact \ \ 1-cochains  \right \}}}
>>$$
